# Chef Academy Database

## Overview
Chef Academy Database is a relational database project for an online cooking education platform. It organizes courses, recipes, instructors, students, enrollments, and recipe submissions.

## Features
- Instructor and course management
- Recipe management
- Student enrollment in courses
- Recipe assignment submissions
- Relational database design and data integrity

## Database Entities
- Instructor
- Student
- Course
- Enrollment
- Recipe
- RecipeSubmission

## Technologies
- SQL
- Relational Database Design
- Entity-Relationship Diagram (ERD)

## Project Files
- `chef_academy.sql` — SQL database script
- `ChefAcademy_DB.pdf` — Project documentation and database diagrams

## Purpose
The project demonstrates relational database design, relationships between entities, and the organization of data for an online culinary learning platform.
